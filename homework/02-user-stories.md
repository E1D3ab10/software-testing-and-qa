# Домашнее задание 2. Истории пользователя для Telegram

## 1. Сообщение без интернета

Как пользователь Telegram, я хочу отправить сообщение даже при пропавшем интернете, чтобы не набирать его заново после восстановления связи.

### Критерии приемки

1. Если нажать отправку без интернета, сообщение остается в чате. Рядом с ним виден значок ожидания.
2. После восстановления связи сообщение приходит собеседнику без повторного нажатия на отправку.
3. Собеседник получает сообщение один раз, даже если связь пропадала несколько раз.
4. После отправки значок ожидания исчезает.

## 2. Ограничение прав в группе

Как администратор группы, я хочу запретить конкретному участнику писать сообщения, чтобы остановить спам в чате.

### Критерии приемки

1. Администратор выбирает участника и запрещает ему отправлять сообщения.
2. После сохранения настроек этот участник не может отправить сообщение в группу. Приложение показывает, что писать в группу нельзя.
3. Остальные участники могут писать как раньше.
4. Участник без прав администратора не может менять ограничения других людей.
5. Если администратор снимет запрет, участник снова сможет писать в группу.
