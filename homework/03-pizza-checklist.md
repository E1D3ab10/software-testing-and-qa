# Домашнее задание 3. Чек-лист выбора ингредиентов

Для проверок открыть раздел выбора ингредиентов у базовой пиццы. Каждый ингредиент проверять отдельно, затем проверять сочетания из нескольких ингредиентов.

## Доступные ингредиенты

| Ингредиент | Цена за порцию, руб. |
| --- | ---: |
| Пепперони | 60 |
| Ветчина | 70 |
| Грибы | 50 |
| Лук | 30 |
| Оливки | 40 |
| Бекон | 80 |

- [ ] В списке доступны все шесть ингредиентов из таблицы.
- [ ] Названия и цены ингредиентов соответствуют таблице.

## Добавление ингредиентов

- [ ] При пустом составе доступны кнопки добавления всех шести ингредиентов.
- [ ] Каждый ингредиент можно добавить в пустой состав. Добавляется одна порция выбранного ингредиента.
- [ ] При добавлении ингредиента остальные выбранные ингредиенты остаются в составе.
- [ ] После добавления ингредиента кнопка добавления этого же ингредиента блокируется. Проверить для каждого из шести ингредиентов.
- [ ] Пока выбрано меньше пяти ингредиентов, кнопки добавления ещё не выбранных ингредиентов доступны.
- [ ] Повторное нажатие на заблокированную кнопку не добавляет вторую порцию и не меняет стоимость.
- [ ] Несколько быстрых нажатий на добавление одного ингредиента не приводят к появлению нескольких порций.

## Минимум и максимум ингредиентов

- [ ] Если в составе нет ингредиентов, появляется уведомление «Необходимо добавить хотя бы один ингредиент».
- [ ] При отсутствии ингредиентов кнопка удаления заблокирована. Нажатие на неё не меняет состав и стоимость.
- [ ] После добавления первого ингредиента уведомление о пустом составе исчезает, удаление становится доступно.
- [ ] Состав из одного ингредиента допустим. Уведомление о необходимости добавить ингредиент не появляется.
- [ ] Составы из двух, трёх и четырёх разных ингредиентов допустимы.
- [ ] При добавлении пятого ингредиента в составе остаётся ровно пять ингредиентов, все кнопки добавления блокируются.
- [ ] При пяти выбранных ингредиентах заблокирована и кнопка добавления шестого, ещё не выбранного ингредиента. Добавить его нельзя.
- [ ] Блокировка при пяти ингредиентах работает для любого набора. По очереди оставлять невыбранным каждый из шести ингредиентов.
- [ ] Если при четырёх выбранных ингредиентах быстро нажать добавление двух оставшихся, в составе не оказывается больше пяти ингредиентов.

## Удаление ингредиентов

- [ ] Каждый добавленный ингредиент можно удалить. Проверить отдельно для всех шести ингредиентов.
- [ ] При удалении исчезает только выбранный ингредиент, остальные остаются в составе.
- [ ] После удаления ингредиента его снова можно добавить, если в составе меньше пяти ингредиентов.
- [ ] После удаления одного ингредиента из пяти остаётся четыре. Кнопки добавления удалённого и ранее не выбранного ингредиентов становятся доступны, кнопки четырёх оставшихся ингредиентов остаются заблокированы.
- [ ] После повторного добавления удалённого ингредиента в составе есть только одна его порция.
- [ ] Можно заменить один из пяти ингредиентов другим: удалить выбранный и добавить ранее не выбранный. В составе снова пять ингредиентов, все кнопки добавления заблокированы.
- [ ] Можно удалить последний ингредиент. Состав становится пустым, появляется уведомление «Необходимо добавить хотя бы один ингредиент», кнопка удаления блокируется.
- [ ] После удаления последнего ингредиента все кнопки добавления доступны. Добавление нового ингредиента убирает уведомление и снова делает удаление доступным.

## Стоимость

Доплата за ингредиенты считается отдельно от цены базовой пиццы.

- [ ] Добавление каждого ингредиента увеличивает стоимость пиццы на цену одной порции из таблицы.
- [ ] Удаление каждого ингредиента уменьшает стоимость пиццы на цену одной порции из таблицы.
- [ ] Для пепперони, ветчины, грибов, лука и оливок доплата составляет 250 руб.
- [ ] Если из этого набора удалить грибы, доплата становится 200 руб. Если затем добавить бекон, доплата становится 280 руб.
- [ ] После добавления и удаления одного и того же ингредиента стоимость возвращается к значению до добавления.
- [ ] После удаления всех ингредиентов доплата равна 0 руб., остаётся только стоимость базовой пиццы.
