# Домашнее задание 3. Чек-лист выбора ингредиентов

## Доступные ингредиенты

| Ингредиент | Цена за порцию, руб. |
| --- | ---: |
| Пепперони | 60 |
| Ветчина | 70 |
| Грибы | 50 |
| Лук | 30 |
| Оливки | 40 |
| Бекон | 80 |

- [ ] В списке есть все шесть ингредиентов, их названия и цены совпадают с таблицей.

## Добавление ингредиентов

- [ ] Каждый из шести ингредиентов можно добавить. Добавляется одна порция.
- [ ] Добавление нового ингредиента не меняет остальные ингредиенты в пицце.
- [ ] Можно по очереди добавить от одного до пяти разных ингредиентов.
- [ ] После добавления ингредиента его кнопка добавления блокируется.
- [ ] Если выбрано меньше пяти ингредиентов, остальные можно добавить.
- [ ] Повторное нажатие, в том числе быстрое, не добавляет вторую порцию одного ингредиента.
- [ ] После добавления пятого ингредиента все кнопки добавления заблокированы, включая кнопку шестого ингредиента.
- [ ] Шестой ингредиент добавить нельзя. Проверить, по очереди оставляя невыбранным каждый из шести ингредиентов.
- [ ] Если при четырёх ингредиентах быстро нажать добавление двух оставшихся, в пицце будет не больше пяти ингредиентов.

## Удаление ингредиентов

- [ ] Любой добавленный ингредиент можно удалить. Проверить по очереди для всех шести.
- [ ] Удаляется только выбранный ингредиент, остальные остаются в пицце.
- [ ] Если удалить один ингредиент из пяти, остаётся четыре. Кнопки добавления двух отсутствующих ингредиентов становятся доступны.
- [ ] Кнопки добавления оставшихся ингредиентов после удаления по-прежнему заблокированы.
- [ ] Удалённый ингредиент можно добавить снова, но только одну порцию.
- [ ] Если заменить один из пяти ингредиентов другим, все кнопки добавления снова блокируются.
- [ ] Если удалить последний ингредиент, появляется уведомление «Необходимо добавить хотя бы один ингредиент».
- [ ] При пустом составе кнопка удаления заблокирована, все кнопки добавления доступны.
- [ ] После добавления первого ингредиента уведомление исчезает, кнопка удаления становится доступна.

## Стоимость

- [ ] При добавлении ингредиента цена пиццы увеличивается на стоимость его порции.
- [ ] При удалении ингредиента цена пиццы уменьшается на стоимость его порции.
- [ ] Для пепперони, ветчины, грибов, лука и оливок доплата составляет 250 руб.
- [ ] Если из этого набора удалить грибы, доплата будет 200 руб. Если затем добавить бекон — 280 руб.
- [ ] После удаления всех ингредиентов остаётся только цена базовой пиццы.
